Lesson 18 · Building the Pages

The Contact Page: Forms, Map & FAQ

The last page! It has contact info cards, a full contact form, a map banner, and a FAQ where each question opens to reveal its answer. That last part uses a built-in HTML feature that needs no JavaScript at all.

  • About 60 minutes
  • Edits: contact.html

By the end of this lesson you will be able to

  • Build an accessible form with <label>, <input>, <select> and <textarea>.
  • Use input types and required for free browser validation.
  • Style form fields, including a focus glow with :focus.
  • Make phone and email links with tel: and mailto:.
  • Build an accordion with <details> and <summary>.

Form elements explained

ElementWhat it does
<label for="name">The visible name of a field. Its for matches the field's id, so clicking the label puts the cursor in the field, and screen readers announce it.
type="text" / "email" / "tel"Plain text, an email address (checked automatically), and a phone number (phones show a number keypad).
name="…"The name each answer is sent under when the form is submitted.
<select> + <option>A dropdown list. The first option is disabled selected with an empty value: it shows “Select a service” but can't be chosen, so required forces a real choice.
<textarea>A multi-line text box for longer messages. It needs a closing tag.
requiredThe browser refuses to submit until this field is filled in.

Does the form actually send email?

No. Sending a message needs a server, which is beyond HTML and CSS. With action="#", a valid form just reloads the page. (The original site shows a JavaScript pop-up instead.) Later, you can connect it to a free form service, which usually means changing only the action attribute and adding method="post".

Style the form

Add to the <style> block:

  • One rule styles all three field types at once using a grouped selector (commas).
  • font-family: inherit: form fields don't use the page font by default, so this makes them use Inter.
  • :focus applies while you're typing in a field. The blue border plus a soft 3px box-shadow “ring” shows clearly which field is active.
  • resize: vertical lets visitors drag the message box taller, but not wider.
  • .form-row is a two-column grid that puts Name/Email and Phone/Service side by side.

Try submitting the empty form. The browser points out the first required field.

Add the FAQ with <details>

HTML has a built-in “click to open” element:

  • <details> is a box that is closed by default.
  • <summary> is the part that is always visible. Clicking it opens and closes the box.
  • When open, the browser adds an open attribute to <details>, which CSS can detect with [open].
  • Giving several <details> the same name="faq" makes them an exclusive group: opening one closes the others, just like the original site. Older browsers simply let several stay open, which is fine.

  • .faq-item[open] .faq-question i rotates the chevron 180° when that item is open.
  • align-items: start on the grid stops an opened question from stretching its neighbour.

Common mistakes

  • Clicking a label does nothing: the label's for must exactly match the field's id.
  • The whole page after the form is inside the textarea: you forgot </textarea>.
  • Two arrows show in the FAQ: the default marker wasn't removed. Check list-style: none on .faq-question.
