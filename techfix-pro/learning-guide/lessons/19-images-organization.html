Lesson 19 · Polish, Publish & Submit

Managing Images & Organising Your Project

So far every photo has come straight from the internet (Unsplash). Real websites usually keep their own images in the project. In this lesson you will add your own pictures, master file paths, and tidy up your project like a professional.

  • About 45 minutes
  • Edits: images/, index.html

By the end of this lesson you will be able to

  • Explain the difference between remote (online) and local images.
  • Save, name and size images correctly.
  • Write correct relative paths from HTML and from CSS.
  • Write good alt text.
  • Keep a multi-page project organised.

Remote images vs local images

Remote imageLocal image
Path looks likehttps://images.unsplash.com/photo-…?w=600images/team-alex.jpg
StoredOn someone else's serverIn your project's images folder
ProsNothing to download or store; easy to try outYou control it; works offline; it won't disappear
ConsNeeds internet; could be removed or changedYou must size and compress it yourself

TechFix Pro uses remote Unsplash images throughout. A useful trick in those addresses: ?w=600&h=400&fit=crop asks Unsplash for a version 600px wide and 400px tall, cropped to fit. That's why the small testimonial photos use w=100&h=100.

Understanding paths

A path tells the browser where to find a file. A relative path starts from the location of the file you're writing in:

techfix-pro/ ├── index.html ← you are writing here ├── styles.css └── images/ └── workshop.jpg
PathMeans
about.htmlA file in the same folder.
images/workshop.jpgGo into the images folder, then find workshop.jpg.
../workshop.jpg.. means go up one folder (to the parent), then find the file.
https://…An absolute address on the internet.

Paths in CSS are relative to the CSS file

A url() inside styles.css is measured from where styles.css lives. A url() inside a page's <style> block is measured from the HTML file. In TechFix Pro both sit in the same folder, so url('images/hero.jpg') works in either place. If you ever move your CSS into a css/ folder, you'd need url('../images/hero.jpg').

Download an image

  1. Go to unsplash.com (free photos) and search for something like circuit board or phone repair.
  2. Open a photo, click the arrow next to Download and choose Medium or Large (not “Original”, which is far too big for a website).
  3. Find the file in your Downloads folder.

Name it and move it into images/

Rename the file to something short and descriptive, using lowercase letters and hyphens. For example, rename john-doe-AbC123xyz-unsplash.jpg to hero-circuit.jpg. Then move it into my-websites/techfix-pro/images/. You can also drag it from your file manager straight onto the images folder in VS Code's Explorer.

Image best practices

  • Choose the right format: .jpg for photos, .png for graphics with sharp edges or transparency, .svg for logos and icons, and .webp for smaller photos (all modern browsers support it).
  • Size them sensibly: a full-width background needs to be about 1920px wide; a card photo about 600–800px. Aim for under 300 KB per photo. Free tools like squoosh.app can shrink an image in seconds.
  • Always write alt text that describes the image's purpose: alt="Technician repairing electronics", not alt="image". Purely decorative images can use an empty alt="".
  • Let CSS crop, not stretch: give the image a fixed height and use object-fit: cover, as TechFix Pro does for every card photo.
  • Lazy-load images below the fold with loading="lazy".
  • Respect licences: Unsplash photos are free to use; random Google Images results usually are not.

Organising your project

Here is your finished project. Compare it with your folder:

my-websites/ ├── practice/ ← Lessons 1–3 experiments │ ├── first.html │ ├── hello.html │ └── style.css └── techfix-pro/ ← open THIS folder in VS Code ├── index.html ├── about.html ├── services.html ├── blog.html ├── gallery.html ├── contact.html ├── styles.css ← shared by all pages └── images/ ├── hero-circuit.jpg └── about-technician.jpg

Habits of tidy developers

  1. One project, one folder. Open the project folder itself in VS Code, not a parent folder or a single file.
  2. Lowercase, hyphenated names for every file and folder.
  3. Shared styles go in styles.css; page-only styles go in that page's <style>. If you find yourself copying the same CSS into two pages, move it to styles.css, as we did with the page header.
  4. Use comments as signposts: /* ===== Footer ===== */ in CSS and <!-- Hero Section --> in HTML.
  5. Keep consistent indentation (Shift + Alt + F).
  6. Back up your work. Right-click the techfix-pro folder → Compress / Send to → Compressed (zipped) folder after each lesson, or learn Git when you're ready.
