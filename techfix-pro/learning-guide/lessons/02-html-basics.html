HTML Basics

HTML is the language that describes what is on a page. In this lesson you will learn how HTML is written, the standard “starter” code every page needs, and the dozen tags you will use most often.

  • About 60 minutes
  • Creates: practice/hello.html

By the end of this lesson you will be able to

  • Explain what tags, elements and attributes are.
  • Write the HTML “boilerplate” every page starts with.
  • Use headings, paragraphs, bold/italic text, lists, links and images.
  • Group content with <div>, <span> and meaningful section tags.
  • Write comments and indent your code neatly.

Tags, elements and attributes

HTML stands for HyperText Markup Language. You “mark up” your content by wrapping it in tags. A tag is a word inside angle brackets, like <p>. Most tags come in pairs: an opening tag and a closing tag (the closing tag has a forward slash /).

<aopening tag hrefattribute name="about.html"attribute value>About uscontent</a>closing tag

The whole thing — opening tag, content and closing tag — is called an element. This one is a link that says “About us” and goes to about.html when clicked.

New terms

Tag — a keyword in angle brackets, like <h1>.
Element — an opening tag + its content + its closing tag.
Attribute — extra information inside an opening tag, written as name="value". For example href="about.html" tells a link where to go.
Void element — an element with no content and no closing tag, like <img> or <br>.

Nesting

Elements can sit inside other elements. This is called nesting. The rule: close tags in the reverse order you opened them — like putting a box inside a box.

The page “boilerplate”

Every HTML page starts with the same few lines. Developers call this the boilerplate. Here is what each line means:

LineWhat it does
<!DOCTYPE html>Tells the browser “this is a modern HTML5 page”. Always the very first line.
<html lang="en">Wraps the whole page. lang="en" says the page is in English (helps screen readers and search engines).
<head>Information about the page that is not shown in the page itself: its title, character set, and links to CSS files.
<meta charset="UTF-8">Lets the page show every kind of character correctly (é, ñ, —, ©, emoji…).
<meta name="viewport" …>Makes the page fit phone screens properly. Essential for responsive design (Lesson 9).
<title>The text shown on the browser tab and in search results.
<body>Everything visible on the page goes inside here.

Shortcut: let VS Code type it for you

In an empty .html file, type a single exclamation mark ! and press Tab (or Enter). VS Code writes the whole boilerplate for you! This feature is called Emmet. Just change the text inside <title>.

The tags you will use most

TagPurposeUsed in TechFix Pro for…
<h1> … <h6>Headings, from most important (h1) to least (h6). Use one h1 per page.Page titles, section titles, card titles
<p>A paragraph of text.All body text
<strong>, <em>Important (bold) and emphasised (italic) text.—
<a href="…">A link to another page or website.Menu links, buttons, “Read More”
<img src="…" alt="…">An image. src = where the picture is; alt = a text description.Photos everywhere
<ul>, <ol>, <li>Bulleted list, numbered list, and a list item.Menus, feature lists, footer links
<div>A generic box for grouping things. Has no meaning on its own.Cards, grids, wrappers
<span>A generic wrapper for a few words inside a line.Coloured words, small labels
<br>A line break inside text.Addresses on the Contact page

Meaningful (“semantic”) section tags

These work like <div> but also say what kind of content they hold. Screen readers and search engines use that meaning. TechFix Pro uses all of these:

TagMeaning
<nav>The main navigation menu.
<header>An introductory area, like the dark title banner at the top of inner pages.
<section>A themed group of content, usually with a heading (e.g. “Our Repair Services”).
<article>A self-contained piece, like a blog post card.
<aside>Side content, like the blog sidebar.
<footer>The bottom area of a page.

Create hello.html

In VS Code (with your practice folder open), create a new file called hello.html. Type ! and press Tab to get the boilerplate. Change the title to My First Page.

Add content inside <body>

Click between <body> and </body> and type the following. Read the explanations below while you type.

  • <!-- … --> is a comment. The browser ignores it. Use comments to leave notes for yourself.
  • <ul> makes a bulleted list; each <li> is one bullet.
  • The <a> tag's href attribute is the address the link goes to.
  • The <img> tag has no closing tag. Its src is the address of a photo on the internet, and alt describes the picture for people who cannot see it.

Save and view

Save (Ctrl + S) and open the page with Live Server (right-click → Open with Live Server).

It looks plain — that is normal! HTML only describes what is on the page. In the next lesson CSS will make it look good.

Writing tidy code

Indent nested elements with 4 spaces (or press Tab) so you can see which element is inside which. The browser does not care about spaces and blank lines — but you will, when you are hunting for a missing tag.

Auto-format

Press Shift + Alt + F (Windows) or Shift + Option + F (Mac) and VS Code fixes the indentation of the whole file for you.

Special characters

Because < and > mean “tag”, a few characters have special codes called entities. TechFix Pro uses &copy; to show the © symbol in its footer. Others you may need: &lt; (<), &gt; (>) and &amp; (&).

Checkpoint

Common mistakes in this lesson

  • The image does not show: check the src address is typed exactly, inside straight quotes ", and that you are online.
  • Everything after a point is bold or a link: you forgot a closing tag (</strong> or </a>).
  • Curly quotes: if you copied code from a word processor you may have “smart quotes” (“ ”). HTML needs straight quotes " ".

Practice

  1. Add an <h2> called My favourite devices followed by a numbered list (<ol>) of three devices.
  2. Make the word “paragraph” in the first paragraph italic.
  3. Add a link that opens first.html (from Lesson 1). Hint: href="first.html".
