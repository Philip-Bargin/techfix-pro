Lesson 15 · Building the Pages

The Services Page

The Services page has three detailed service rows that alternate sides, three pricing cards (one “Most Popular”), and a four-step process with a line connecting the steps.

  • About 60 minutes
  • Edits: services.html

By the end of this lesson you will be able to

  • Alternate background colours with :nth-child(even) and :nth-child(odd).
  • Flip a two-column layout with direction: rtl.
  • Centre an absolutely-positioned badge with left: 50% + translateX(-50%).
  • Draw a connecting line behind a row of circles.

Two clever tricks in the CSS you already added

  • Alternating backgrounds: .service-detail:nth-child(even) selects service sections that are an even-numbered child of <body>. Counting the body's children: the nav is 1st, the header 2nd, row 1 is 3rd (odd, white), row 2 is 4th (even, light grey), row 3 is 5th (odd, white). The rows alternate automatically.
  • Swapping sides: .detail-grid.reverse { direction: rtl; } tells the grid to lay out its columns right-to-left (the way Arabic and Hebrew are written), so the image goes on the left. .detail-grid.reverse > * { direction: ltr; } switches the text inside back to left-to-right so it reads normally. (* means “any element”.)

CSS:

  • The middle card has two classes, pricing-card featured. .pricing-card.featured (no space) matches only cards with both classes and gives it a thicker blue border.
  • Centring the badge: left: 50% puts the badge's left edge at the middle of the card. transform: translateX(-50%) then slides it back by half of its own width, so its centre lines up with the card's centre. top: -12px makes it sit across the top border.
  • .price span makes “/service” small and grey next to the big price.
  • The buttons use an inline style, style="width:100%", to stretch across the card.

Checkpoint

Compare your page with the screenshots in this lesson. If anything looks different, go back to the step for that section and check your code against the code box, line by line.

Common mistakes

  • All rows have the same background: :nth-child counts every child of <body>. If you left an extra element (like a test <div>) between the navbar and the rows, the counting shifts.
  • Row 2's text is right-aligned or punctuation looks odd: you're missing .detail-grid.reverse > * { direction: ltr; }.
  • The line goes through the circles: .step-number needs background: var(--white), and .step needs position: relative; z-index: 1.
