Lesson 8 · Shared Styles & Layout

The Footer & CSS Grid

The dark footer at the bottom of every page has four columns: the brand with social icons, two columns of links, and the contact details. You will build it with CSS Grid, the most powerful layout tool in CSS.

  • About 45 minutes
  • Edits: all 6 HTML pages, styles.css

By the end of this lesson you will be able to

  • Create a multi-column layout with display: grid and grid-template-columns.
  • Use the fr unit to share space between columns.
  • Make perfect circles with border-radius: 50%.
  • Use special characters like &copy;.

The structure is: footer → .container → .footer-grid (with 4 children: .footer-brand and three .footer-columns) → .footer-bottom (the copyright line).

  • The social icons use fab (Font Awesome brands).
  • aria-label="Facebook" gives each icon-only link a name that screen readers can announce, since there's no visible text.
  • &copy; displays the © symbol.
  • The last column has two classes: footer-column footer-contact. It gets the general column styles plus some contact-specific ones.

Understand the grid

The key line is:

  • display: grid turns the element into a grid. Its direct children become grid items, placed into columns automatically.
  • grid-template-columns lists the width of each column. There are four values, so there are four columns.
  • fr means “fraction of the free space”. The total is 1.6 + 1 + 1 + 1.2 = 4.8 parts, so the brand column gets 1.6 / 4.8 = one third of the width, and each link column gets 1 / 4.8.
  • gap: 3rem puts 3rem of empty space between the columns.

Flexbox or Grid?

Use flexbox for a single row or column of items (a navbar, a row of buttons, an icon next to text). Use grid when you want items lined up in columns (and rows), like the footer, card grids and photo galleries. TechFix Pro uses both everywhere.

Other new ideas in the footer CSS:

  • .social-links a is a 38×38px square with border-radius: 50%, which makes a perfect circle. Flexbox centres the icon inside.
  • rgba(255,255,255,0.08) is white at 8% strength: a very subtle light circle on the dark background.
  • .footer-column ul li a:hover { padding-left: 4px; } nudges links slightly right on hover.
  • align-items: flex-start in .footer-contact p lines the icon up with the first line of text.

Copy the footer to every page

Select from <!-- Footer --> to </footer> in index.html, copy it, and paste it into the other five pages in the same place (below <!-- PAGE CONTENT GOES HERE -->, above </body>). Unlike the navbar, the footer is identical on every page, so nothing needs changing.

Checkpoint

The footer is right under the navbar!

That's normal for now, because there is no page content between them yet. The fixed navbar may even cover the top of the footer. It will look right as soon as you add the page sections.

Common mistakes

  • Columns are stacked instead of side by side: check class="footer-grid" is on the <div> that directly contains the four columns.
  • Five columns or an empty gap: a missing </div> can move a column inside another one. Use Shift + Alt + F to re-indent and spot it.
  • The text is invisible: make sure .footer has color: var(--white) and the background is var(--secondary).

Practice

Use DevTools (F12) to inspect .footer-grid. In Chrome and Edge, click the small grid badge next to it in the Elements panel. Coloured lines show you exactly where each column is. Try changing 1.6fr to 3fr in DevTools and watch the brand column grow.
