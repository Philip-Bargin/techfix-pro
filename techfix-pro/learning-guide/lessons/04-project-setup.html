Lesson 4 · Getting Started

Creating the TechFix Pro Project

Time to start the real website! You will create all the files the project needs, give every page its starter code, and connect each page to Google Fonts, the Font Awesome icon library and your shared stylesheet.

  • About 40 minutes
  • Creates: 6 HTML pages, styles.css, images/

By the end of this lesson you will be able to

  • Plan and create a clean folder structure for a multi-page website.
  • Explain why the site has one shared CSS file plus a small <style> block on each page.
  • Load a web font and an icon library from a CDN.
  • Use Font Awesome icons with the <i> tag.

The project's structure

Here is every file you will create (including an images folder for your own pictures, which you will use in Lesson 19):

techfix-pro/ ├── index.html ← Home page (must be called index.html) ├── about.html ← About Us ├── services.html ← Our Services ├── blog.html ← Blog (in the "Media" menu) ├── gallery.html ← Gallery (in the "Media" menu) ├── contact.html ← Contact Us ├── styles.css ← styles SHARED by every page └── images/ ← your own photos (Lesson 19)

Why is the home page called index.html?

When someone visits a website address without naming a file (like www.techfixpro.com), web servers automatically look for a file called index.html. So the home page of almost every website is named index.html.

How the styling is split

Every page links to the same styles.css. It holds anything used on more than one page: colours, fonts, buttons, the navbar, the footer and so on. Each page also has its own <style> block in its <head> for things only that page uses, like the Home page's hero or the Gallery's photo grid.

This is how TechFix Pro is built. The benefit: when you change the brand colour in styles.css, all six pages update at once.

Open the techfix-pro folder in VS Code

In Lesson 1 you made an empty folder at Documents/my-websites/techfix-pro. In VS Code choose File → Open Folder…, select that folder and click Select Folder. The Explorer panel now shows TECHFIX-PRO.

Use your own folder

Always build in Documents/my-websites/techfix-pro, the folder you created in Lesson 1. Keep everything for this project in there: it is exactly what you will upload to GitHub in Lesson 22.

Create the files and the images folder

Hover over TECHFIX-PRO in the Explorer and click the New File icon. Create these seven files, one at a time, typing each name exactly:

index.html · about.html · services.html · blog.html · gallery.html · contact.html · styles.css

Then click the New Folder icon (next to New File) and create a folder called images.

Understand the three external links

Every page's <head> will contain these three lines. Here is what each one loads:

LineWhat it loads
<link href="https://fonts.googleapis.com/css2?family=Inter…">The Inter font from Google Fonts, in weights 300 (light) to 800 (extra bold).
<link … font-awesome/6.4.0/css/all.min.css">Font Awesome: a free library of 2,000+ icons (the microchip logo, phone, wrench, stars…). It is just a CSS file and an icon font — no JavaScript.
<link rel="stylesheet" href="styles.css">Your shared stylesheet. It is listed last so your styles win if there is a conflict.

New term: CDN

A Content Delivery Network is a set of fast servers around the world that host popular files (like fonts and icon libraries) so every website can link to them instead of storing its own copy. Because these files come from the internet, you must be online for fonts and icons to appear.

How Font Awesome icons work

An icon is an empty <i> element with two classes:

  • A style class: fas (solid), far (regular / outline) or fab (brands, like Facebook or Apple).
  • An icon name class starting with fa-, like fa-microchip, fa-phone or fa-star.

Icons behave like text: they take the colour and size of their surroundings, so you style them with color and font-size. Browse all free icons at fontawesome.com.

Checkpoint

I see an empty square instead of the icon

  • Check the Font Awesome <link> line letter-by-letter — especially 6.4.0 and all.min.css.
  • Check you are connected to the internet.
  • Check the class: fas fa-microchip (with a space between the two classes, and a hyphen inside fa-microchip).
