Lesson 21 · Polish, Publish & Submit

Practice Exercises & Final Project Checklist

You've built a complete six-page website with nothing but HTML and CSS. Use the checklist to make sure everything is perfect, then try the exercises to make the site your own.

Practice exercises

These build confidence by changing the site yourself. Each one uses skills from a specific lesson. Make a backup copy of your folder first!

1. Rebrand the site (Lesson 5)

Change TechFix Pro's brand colour to green by editing only the variables in :root. Use --primary: #059669;, --primary-dark: #047857; and --primary-light: #10b981;.

Look closely: a few things stay blue. Can you find them? (Hint: search the files for rgba(37, 99, 235 and #eff6ff, places where the blue was written directly instead of with a variable.) What does that teach you about using variables everywhere?

2. Add a fourth service (Lessons 11 & 15)

Add a “Smartwatch Repair” card to the Home page services (icon: fas fa-clock) and a matching detail row on the Services page. Should it have the reverse class? Do the backgrounds still alternate?

3. Create a new page (Lessons 4, 7, 8, 14)

Create careers.html with the skeleton, the navbar, a page header (“Join Our Team”), one section with three job cards (reuse the .value-card CSS idea), and the footer. Then link the footer's “Careers” item to it.

Show a starting point for the page header

4. Extend the gallery (Lesson 17)

Add a tenth photo with a new category, “Events”. You'll need: a new photo link (#photo-10, data-category="events"), a new lightbox, a new radio and label, a new highlight selector and a new hide selector.

5. Add FAQ questions (Lesson 18)

Add two more questions to the FAQ, for example “Do you sell refurbished devices?” and “What payment methods do you accept?”. Copy an existing <details> block.

6. Stretch goal: a dark section (Lessons 5 & 13)

Give the testimonials section a dark background (var(--secondary)) and white heading text, while keeping the cards white. Which selectors do you need to add or change?

7. Your own website

The best way to lock in what you've learned: start a fresh folder and build a small site of your own, like a personal portfolio, a club website or a shop, reusing the TechFix Pro patterns (navbar, hero, card grid, footer).

Where to go next

  • Publish and submit your site: Lesson 22 walks you through GitHub Pages and Google Classroom.
  • Learn more CSS: the MDN Web Docs are the best free reference for every HTML element and CSS property.
  • Practise layouts: Flexbox Froggy and Grid Garden are free games that teach flexbox and grid.
  • When you're ready: JavaScript adds behaviour, like the scroll-triggered animations and form pop-ups in the original TechFix Pro.

Congratulations!

You started with an empty folder and finished with a professional, responsive, multi-page website. That's a real achievement. Be proud of it, and keep building!
