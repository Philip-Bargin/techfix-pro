Reference

Glossary

Every new word from the course, in plain English, with the lesson where it first appears.

TermMeaningLesson
::before / ::afterPseudo-elements: extra boxes CSS can add before/after an element's content, used for decorations. They need content.3, 11
:checkedMatches a checkbox or radio button that is ticked/selected.9, 17
:focus / :focus-withinMatches an element that is active for typing or keyboard use / an element containing one.7, 18
:hoverMatches an element while the mouse pointer is over it.3
:not()Matches elements that do not match the selector inside the brackets.17
:nth-child()Matches elements by their position among their siblings (e.g. even or odd).15
:rootThe top-level <html> element; where CSS variables are defined.5
:targetMatches the element whose id is in the address bar after #.17
~ (sibling combinator)Selects elements that come after another element with the same parent.9
Absolute positioningposition: absolute: placed at exact coordinates inside the nearest positioned parent, taken out of the normal flow.7
AccessibilityMaking sites usable by everyone, including people using screen readers or keyboards.8
alt textA text description of an image for screen readers and when the image fails to load.2, 19
Animation / @keyframesA named sequence of style changes over time, played with the animation property.9
aria-labelAn attribute giving an element an accessible name (useful for icon-only links).8
aspect-ratioKeeps an element at a fixed width-to-height shape, e.g. 4/3.17
AttributeExtra information in an opening tag, written name="value".2
Attribute selectorCSS that matches an attribute value, e.g. [data-category="team"].17
Block / inlineBlock elements start on a new line and fill the width; inline elements flow within text.3
BoilerplateThe standard starter code every HTML page needs.2
Box modelEvery element is content + padding + border + margin.3
box-sizing: border-boxMakes width include padding and border.5
BreadcrumbsA trail of links showing where a page sits (Home › Media › Blog).6
BreakpointA screen width at which the layout changes (1024px, 768px, 480px).9
BrowserThe program used to view websites (Chrome, Edge, Firefox, Safari).1
CascadeThe rules that decide which CSS wins when several rules conflict (specificity, then order).3
CDNContent Delivery Network: servers that host shared files like fonts and icon libraries.4
ClassA reusable name given to elements with class="…" and targeted in CSS with a dot.3
clamp()A size with a minimum, preferred and maximum value, e.g. clamp(2.2rem, 5vw, 3.8rem).10
CommitSaving a set of changes to a GitHub repository, with a short message.22
CommentA note the browser ignores: <!-- … --> in HTML, /* … */ in CSS.2, 3
ComponentA reusable piece of design (button, card, navbar).6
ContainerThe .container wrapper that limits content to 1200px and centres it.5
CSSCascading Style Sheets: the language that styles HTML.3
CSS variable (custom property)A named reusable value like --primary, used with var().5
data-* attributeYour own custom attribute for storing information on an element.17
<details> / <summary>Built-in HTML open/close box and its always-visible heading.18
Developer Tools (DevTools)Browser tools (F12) for inspecting HTML and CSS.3
ElementOpening tag + content + closing tag.2
EmmetVS Code shortcuts, e.g. ! + Tab writes the boilerplate.2
EntityA code for a special character, e.g. &copy; → ©.2
Extension(1) The letters after a file name's dot. (2) An add-on for VS Code like Live Server.1
External / internal / inline CSSCSS in a separate file / in a <style> tag / in a style attribute.3
filterVisual effects such as grayscale().13
Fixed positioningposition: fixed: stays in the same place in the window while scrolling.7
Flexboxdisplay: flex: lays out items in a row or column.7
Font AwesomeA free icon library used through <i class="fas fa-…">.4
frA fraction of the free space in a grid.8
GitHubA free website for storing and sharing code projects.22
GitHub PagesA free GitHub feature that publishes HTML and CSS files as a public website at username.github.io.22
Google ClassroomThe online classroom where you submit your website link.22
GradientA smooth blend of colours: linear-gradient() or radial-gradient().3, 12
Griddisplay: grid: lays out items in columns and rows.8
HeroThe large introductory section at the top of a home page.10
HTMLHyperText Markup Language: describes the content and structure of a page.2
idA unique name for one element, targeted in CSS with # and used for #links.3
index.htmlThe default file a server shows for a folder: the home page.4
insetShorthand for top, right, bottom and left.10
Lazy loadingloading="lazy": images download only when scrolled near.11
LightboxA full-screen overlay showing a larger image.17
Live ServerA VS Code extension that auto-refreshes the browser when you save.1
Media query@media (max-width: …): CSS that applies only at certain screen sizes.9
Modifier classAn extra class that changes a base component, e.g. btn-primary.6
NestingPutting elements inside other elements.2
object-fit: coverCrops an image to fill its box without stretching.11
orderChanges the visual order of grid/flex items.13
overflow: hiddenClips anything that sticks out of an element's box.10
Path (relative / absolute)The location of a file, from the current file / as a full web address.7, 19
prefers-reduced-motionA media query for visitors who asked their device for less animation.9
Radio buttonAn option button where only one in a group can be selected.17
Relative positioningposition: relative: stays in normal flow but becomes the reference for absolute children.7
rem / px / % / vh / vwUnits: root font size / pixels / percent of parent / percent of window height / width.3
Repository (repo)A project folder stored on GitHub.22
ResetCSS that removes browser default spacing so you start clean.5
Responsive designWebsites that adapt to any screen size.9
rgba()A colour with red, green, blue and alpha (transparency).3
SelectorThe part of a CSS rule that picks which elements to style.3
Semantic HTMLTags that describe meaning: <nav>, <section>, <article>…2
Stacking contextA self-contained group of layers; z-index only compares within the same group.11
Sticky positioningposition: sticky: scrolls normally, then sticks at a set distance from the top.16
TagA keyword in angle brackets, like <p>.2
transformMoves, scales or rotates an element visually: translateY(), scale(), rotate().6
transitionAnimates the change between two states (e.g. on hover).6
URLA web address, such as https://your-username.github.io/techfix-pro/.22
ViewportThe visible area of the browser window.2, 9
Void elementAn element with no closing tag: <img>, <br>, <input>, <meta>, <link>.2
VS CodeVisual Studio Code, the free code editor used in this course.1
z-indexControls which overlapping element is drawn on top (higher = in front).7, 10
