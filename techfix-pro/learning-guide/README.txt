TechFix Pro - HTML & CSS Learning Guide
=======================================

START HERE: open  index.html  in your web browser (double-click it).

What is in this folder
----------------------
index.html     The guide's home page: table of contents and how to use the guide.
lessons/       21 numbered, step-by-step lessons plus a glossary.
reference/     The complete finished code of every file, for comparing with your own.
solution/      The finished TechFix Pro website (HTML & CSS only, no JavaScript).
               Open solution/index.html to see what you are building.
assets/        The guide's own stylesheet and screenshots.

The original TechFix Pro website files (one folder up) are not modified by this guide.
Students build their own copy in a separate folder (Documents/my-websites/techfix-pro),
as explained in Lesson 1.

An internet connection is needed for fonts, icons and the Unsplash photos.
