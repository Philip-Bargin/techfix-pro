TechFix Pro Website Guide
=========================

START HERE: open  index.html  in your web browser (double-click it).

What is in this folder
----------------------
index.html     The guide's home page: table of contents and how to use the guide.
lessons/       22 numbered, step-by-step lessons plus a glossary.
               Lesson 22 explains how to publish your site with GitHub Pages
               and submit the link in Google Classroom.
assets/        The guide's own stylesheet and screenshots.
solution/      The finished TechFix Pro website, opened by the "View finished site"
               button in the guide's header.

Students build their own copy, step by step, in a separate folder
(Documents/my-websites/techfix-pro), as explained in Lesson 1.

An internet connection is needed for fonts, icons and photos.
